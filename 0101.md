## Ejercicio 1 - Diseño con Tarjetas CRC


###  Tarjeta CRC : `Libro`

| Clase: Libro | |
|---|---|
| **Responsabilidades** | **Colaboradores** |
| Conocer su título, autor e ISBN | - |
| Conocer el número de ejemplares disponibles | `Préstamo` |
| Prestar un ejemplar (si hay disponibles) | `Préstamo` `Socio` |
| Recibir la devolución de un ejemplar | `Préstamo` |


###  Tarjeta CRC : `Socio`

| Clase: Socio | |
|---|---|
| **Responsabilidades** | **Colaboradores** |
| Conocer su nombre | - |
| Conocer su número de socio | - |
| Conocer su fecha de alta | `Préstamo` `Libro` |


###  Tarjeta CRC : `Préstamo`

| Clase: Préstamo | |
|---|---|
